# Celestron AUX protocol reference

Generated by celestron-aux (`celestron-aux --export-docs`) from its catalog and payload decoders. Names come from captures of real devices and community reverse engineering, not from Celestron documentation.

## Frames

* **AUX packet**: `3B | len | src | dst | cmd | data... | checksum`. `len` counts `src`, `dst`, `cmd` and the data bytes. The checksum is the two's complement of the sum of every byte from `len` through the last data byte.
* **StarSense bulk frame**: `3C | len (4 bytes, big-endian) | payload... | checksum`, with every `3B` in the length and payload escaped as `3B 02 02`. The payload is a star list, 8 bytes per star.

A command number belongs to the device a packet is about: in a packet between a controller (a hand controller, CPWI, this tool) and a device, that is the device, in both the request and the reply. The StarSense AutoGuider's packets to the motors use the motors' commands.
